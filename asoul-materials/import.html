导出与分发

把索引导出成文件，覆盖到站点目录即可让改动跟着站点一起走。

导出选项

如何使用导出的文件：
1. assets-mine.json —— 只含你自己导入的素材，便于备份与分享给你的朋友；
2. assets.json / data.js —— 完整数据。会自动剔除你在素材库删除的素材，并应用移动分类的改动。 把 data.js 覆盖到 assets/js/data.js?v=2，即可把新增素材固化进站点，别人打开也能看到；
3. 素材文件本身记得同步放进 assets/images/ 或 assets/stickers/ 对应目录， 并把 JSON 里的 file 字段改成相对路径。

已删除的内置素材

在素材库大图预览里删除的内置素材会列在这里。删除只是先在本浏览器隐藏，导出 data.js 覆盖站点文件后才对所有人彻底生效；误删可随时恢复。

导入已有索引

选择一个此前导出的 assets-mine.json，或在素材库/导入后台备份的索引文件，恢复你的收藏。

导入的文件仅保存在你自己的浏览器中，不会上传到任何服务器。
