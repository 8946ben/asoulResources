怎么自己往里面加素材

站点是纯静态的，有三种由易到难的扩展方式：

方式怎么做适用场景
① 导入后台
最简单		 打开 导入后台，把文件拖进去 → 核对成员与类型 → 保存到本地素材库。刷新后仍在，也会出现在素材库页面。 自己收藏 / 临时整理
② 导出固化 在导入后台点「导出 data.js」，用它覆盖 assets/js/data.js?v=2，同时把素材文件放进 assets/images/ 或 assets/stickers/，并修正 JSON 里的 file 路径。 想把内容固化进站点、分享给别人
③ 直接改数据 编辑 data/assets.json（或 assets/js/data.js?v=2），按同样的字段结构追加条目即可。 批量导入、脚本化维护

素材条目的字段结构

每条素材就是一个对象，字段含义如下：

字段含义
id唯一标识，不可重复
typesticker / image / audio
memberbella / diana / eileen / fiona / sinuo / group
name显示名称
set所属系列，用于「系列」筛选条
file相对站点的文件路径
w / h / bytes宽高与体积，用于详情展示与排序
tags标签数组，参与搜索
source / sourceUrl来源说明与外链，会显示在详情面板
